# Civ6ModelTool

一个 Blender 插件，用于创建和导出《文明6》自定义 3D 资产（模型、动画、Ast、材质、ArtDef）。

## 环境要求

- **Blender 5.0** 或更高版本
- **Windows** 系统（依赖 .NET Framework）
- **.NET Framework 4.0+**
- **文明6 AssetEditor**：Mod项目需至少运行一次以创建资产文件夹结构

## 安装步骤

1. 下载插件压缩包
2. 打开 Blender，进入 `编辑 > 偏好设置 > 插件`
3. 点击安装插件，选择插件压缩包安装
4. 在 3D 视图中按 `N` 键打开侧栏，选择 `Civ6ModelTool` 分类
