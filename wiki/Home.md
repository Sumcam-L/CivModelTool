# Civ6ModelTool Wiki

欢迎使用 Civ6ModelTool Wiki。本插件用于在 Blender 中创建和导出《文明6》自定义 3D 资产。

## 功能导航

- [导出面板](导出面板) - 将 Blender 场景导出为 Civ6 资产（.fgx / .ast / 材质 / ArtDef）
- [工具面板](工具面板) - 顶点组清理、材质槽清理、形态键清理
- [型态键转骨](型态键转骨) - 将型态键动画转换为骨骼动画
- [插件更新](插件更新) - 从 GitHub 自动检查并安装新版本
- [完整工作流](完整工作流) - 从建模到导出的完整 Unit 制作流程
