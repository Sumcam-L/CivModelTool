# 型态键转骨

Civ6 使用骨骼动画，不支持型态键（Blend Shape）动画。此面板将型态键动画转换为骨骼动画。

---

## 自动转换

### 参数说明

| 参数 | 说明 |
|------|------|
| 目标网格 | 包含型态键的网格物体 |
| 目标骨架 | 要挂载骨骼的骨架（留空则自动创建 `ShapeKey_Armature`） |
| 父骨骼 | 新骨骼的父级（可留空） |
| 舍弃率（%） | 位移量小于最大位移 x 此比例的骨骼会被丢弃，值越大骨骼越少 |
| 权重合并 | 偏移量相同的顶点共用一根骨骼，大幅减少骨骼数量 |
| 方向容差 | 方向接近的顶点合并为一根骨骼，值越大合并越激进（0.0-1.0） |

### 形态键动画列表

- 点击 `+` 自动扫描并添加所有包含型态键关键帧的动作
- 留空则转换所有型态键动画
- 可选择特定动作只转换这些动作

### 操作步骤

1. 选择 **目标网格**（含型态键的 Mesh）
2. 选择 **目标骨架**（已有骨架或留空自动创建）
3. （可选）设置 **父骨骼**
4. 调整 **舍弃率**、**权重合并**、**方向容差**
5. （可选）在列表中选择要转换的动作
6. 点击 **转换动画**

转换过程：
- 为每个受影响的顶点生成骨骼（命名 `SKB_{x}{y}{z}`）
- 创建 `SKB_Root` 父骨骼，所有 SKB 骨骼挂在其下
- 为网格添加顶点组并设置权重
- 按帧计算骨骼位移，插入 LINEAR 关键帧，生成 `SKB_{动作名}` 新动作
- 根据舍弃率丢弃低位移骨骼

7. 转换后可点击 **卸载形态键动画并恢复形态键** 清理型态键数据

## 分割模型

当模型骨骼数超过限制（Unit 60 / Leader 256）时，需要分割网格。

### 自动分割

1. 设置 **骨骼数量限制**（Unit 填 60，Leader 填 256）
2. 确保 **目标网格** 已选中
3. 点击 **自动分割模型**

原理：使用 BFS 连通分量分析，将网格按骨骼限制分割为多个独立网格。自动创建顶点组并分离，保留自定义法线。

### 手动分割

1. 进入编辑模式
2. 选中要分离的顶点
3. 点击 **分割模型（编辑模式）**

分离选中顶点为独立网格，保留自定义法线。
