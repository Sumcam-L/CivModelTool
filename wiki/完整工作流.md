# 完整工作流

从建模到导出的完整 Unit 制作流程。

---

## 1. 建模阶段

- 在 Blender 中完成模型、骨骼绑定、动画
- 确保骨骼数 ≤ 60（使用工具面板查看）
- 如有型态键动画，先用型态键转骨面板转换

## 2. 清理阶段

使用工具面板清理：
- 删除空顶点组
- 删除零权重顶点组
- 清理顶点空绑定
- 清理未使用的材质槽
- 删除空形态键

## 3. 配置阶段

1. **设置项目路径**（指向含 `Assets/` 的 Mod 文件夹）

2. **模型导出设置**：
   - 创建 Geo 文件（如 `my_unit`）
   - 类型设为 `Unit`
   - 添加网格对象
   - UV 数量设为 1（或 3 如需 UV2 功能）

3. **动画导出设置**：
   - 添加动画，类型自动设为 `Unit`
   - 选择对应的 Action

4. **引用文件设置**：
   - 创建 Ast 文件（如 `my_unit`）
   - 类型设为 `Unit`
   - DSG 选择 `Standard_Biped`
   - 在模型引用中添加 `my_unit`
   - 在动画引用中逐个选择动作，或点击一键匹配

5. **材质导出设置**：
   - 选择材质，类型自动匹配
   - 确认贴图槽位正确

6. **（可选）ArtDef**：添加 Unit 实例到 `Units.artdef`

## 4. 导出

点击 **导出** 按钮，插件按顺序执行：

1. **验证** - 检查所有 Ast 的 Geo/Anm 引用类型，不匹配则中止
2. **模型导出** - `.fgx` 输出到 `<ProjectPath>/Geometries/`
3. **动画导出** - `.fgx` 输出到 `<ProjectPath>/Animations/`
4. **Ast 生成** - `.ast` 输出到项目路径
5. **材质导出** - 贴图和材质文件
6. **ArtDef 生成** - XML 注入到 `ArtDefs/`

## 输出文件

| 文件 | 路径 |
|------|------|
| 模型 | `<ProjectPath>/Geometries/my_unit.fgx` |
| 动画 | `<ProjectPath>/Animations/*.fgx` |
| Ast | `<ProjectPath>/my_unit.ast` |
| 材质 | `<ProjectPath>/Materials/` |
| 贴图 | `<ProjectPath>/Textures/` |
| ArtDef | `<ProjectPath>/ArtDefs/Units.artdef` |
