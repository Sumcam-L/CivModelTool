# 导出面板

将 Blender 场景导出为 Civ6 资产文件（`.fgx`、`.ast`、材质、ArtDef）。

面板分为四个区域：常规设置、模型导出、动画导出、引用文件设置。底部为导出按钮（至少勾选一项导出选项时启用）。

---

## 常规设置

设置 **项目路径**，指向你的 Civ6 Mod 项目文件夹。

- 路径下必须存在 `Assets/` 文件夹（需先运行一次 AssetEditor 创建）
- 示例路径结构：`MyMod/Assets/Geometries/`、`MyMod/Assets/Animations/`
- 设置路径后，下方各区域才会启用

---

## 模型导出设置

将网格模型导出为 `.fgx` 格式。

### 操作步骤

1. 勾选 **模型导出设置** 展开面板
2. 点击 `+` 创建新的几何体文件（Geo），输入文件名
3. 选中该 Geo，设置 **类型**（Class）

   | 类型 | 用途 |
   |------|------|
   | Unit | 单位模型 |
   | Leader | 领袖模型 |
   | Leader_ShadowVolume | 领袖阴影体积 |
   | LandmarkModel | 地标/建筑模型 |
   | LandmarkObstructionProfile | 地标遮挡体 |
   | VFXModel | 特效模型 |
   | WonderMovieModel | 奇观电影模型 |
   | DecalGeometry | 贴花几何体 |
   | UILensModel | UI透镜模型 |

4. 点击右侧 `+` 添加网格对象（自动添加当前选中的 Mesh，若网格有父级骨架则一并导出）
5. 设置 **导出UV数量**

   | UV 数量 | 说明 |
   |---------|------|
   | 1（默认） | 基础颜色、金属度、粗糙度、法线等 |
   | 2 | 额外支持 AO、光照贴图，**但会丢失骨骼绑定** |
   | 3 | 同时支持 UV2 功能和骨骼绑定（推荐） |

6. **三角化**：模型含四边面/多边面时勾选，已是三角面则无需勾选

### 注意事项

- Unit 骨骼限制 **60 根**，Leader 限制 **256 根**
- 可创建多个 Geo 文件，各自包含不同网格
- 删除 Geo 时自动清理所有 Ast 中对该 Geo 的引用

## 动画导出设置

将 Blender Action 导出为 `.fgx` 动画文件。

### 操作步骤

1. 勾选 **动画导出设置** 展开面板
2. 点击 `+` 添加动画条目（类型自动设为当前 Ast 允许的类型）
3. 选择 **动作**（Blender Action）
4. 设置 **类型**（Class）

   | 类型 | 用途 |
   |------|------|
   | Unit | 单位动画 |
   | Leader | 领袖动画 |
   | Landmark | 地标动画 |
   | VFX | 特效动画 |
   | WonderMovie | 奇观动画 |
   | CameraAnimation | 摄像机动画 |

5. **按关键字添加**：输入关键字，点击按钮批量添加名称包含该关键字的动作
6. **压缩动画**：默认开启，减小文件体积

### 注意事项

- 动画类型必须与 Ast 类型匹配，否则在 Ast 引用中无法选中
- 修改动画类型时，所有 Ast 中不匹配的动画引用会被自动清空
- 坐标转换自动处理（Z-up -> Y-up，100 倍缩放）

#### 骨架名怎么定：动作的 slot 名

动画导出时，动画最终绑到哪个骨架，是由**动作里每个 slot 的显示名**决定的
（`cmt_exporter/action_data.py` 的 `read_action_data`）。

- 默认情况不用管：slot 一旦绑定到骨架对象，它的显示名会自动变成该对象名，正好就是模型侧世界骨用的名字，两边自然对上。
- 如果 slot **没有绑定**对象，它的显示名会保留你自己起的自定义名，而这种名字常以 `Slot_` 开头。
  这时插件有一条规则：**名字以 `Slot_` 开头、且后面还有字符时，去掉 `Slot_`，用剩下的部分作为骨架名**。
  例：slot 显示名 `Slot_R2T1Daniya` → 骨架名 `R2T1Daniya`。
- 去前缀后找不到对应名字的骨架，会**退回用原始 slot 名再找一次**，所以真有骨架叫 `Slot_xxx` 时也不会导不出来。
- 名字不带 `Slot_` 前缀时行为完全不变。
- 名字恰好等于 `Slot_`（前缀后面没有字符）时不去前缀，按原名处理。

> 这条规则只影响「动画绑哪个骨架」，不影响 `.ast` 里的动画引用名——那用的是 Ast 动画槽位名，两套命名互不干扰。

## 引用文件设置

生成 `.ast`、材质、ArtDef 文件。

### Ast 导出设置

Ast 文件将模型、动画、行为组合为 Civ6 资产引用。

#### 操作步骤

1. 勾选 **引用文件设置** > **Ast导出设置**
2. 点击 `+` 创建 Ast 文件
3. 设置 **文件名**、**类型**（Class）和 **DSG**

   类型决定可用的 DSG 和允许引用的 Geo/Anm 类型：

   | Ast 类型 | 允许的 Geo 类型 | 允许的 Anm 类型 |
   |----------|-----------------|-----------------|
   | Unit | Unit | Unit |
   | Leader | Leader, Leader_ShadowVolume | Leader |
   | Landmark | DecalGeometry, LandmarkModel, LandmarkObstructionProfile | Landmark |
   | VFX | VFXModel | VFX |
   | FireFX | FireFXModel | VFX |
   | WonderMovie | DecalGeometry, WonderMovieModel, WonderMovieCamera, LandmarkObstructionProfile | WonderMovie |
   | UILensAsset | UILensModel | （无动画） |

   DSG 决定动画槽位，修改类型时自动重置为第一个可用 DSG。

4. 选择引用类型标签：**模型引用** / **动画引用** / **行为引用**

   **模型引用**：
   - 点击 `+` 添加，下拉只显示类型匹配的 Geo
   - 类型不匹配的引用标红显示并自动删除

   **动画引用**：
   - 槽位由 DSG 自动生成，不可手动增删
   - 每个槽位显示名称（如 `IDLE_A`、`RUN_A`、`DEATH_A`）
   - 只能选择类型匹配的动作
   - 点击 **一键匹配动画**，按 `{Ast名}_{槽位名}` 规则自动匹配

   **行为引用**：
   - 点击 `+` 添加，选择关联的 Ast 文件

#### 类型约束系统

三层保护防止类型错误：

1. **下拉过滤** - Geo 和 Anm 下拉只显示当前 Ast 类型允许的选项
2. **标红提示** - 列表中不匹配的引用显示红色 ERROR 图标
3. **导出阻断** - 导出时验证所有引用，不匹配则弹窗报错并中止

#### 联动行为

| 触发操作 | 自动行为 |
|----------|----------|
| 改 Ast 类型 | 重置 DSG，重建动画槽位 |
| 改 Ast DSG | 重建动画槽位 |
| 改 Geo 类型 | 从所有 Ast 删除不匹配的引用 |
| 改 Anm 类型 | 清空所有 Ast 中不匹配的动画槽 |
| 删除 Geo | 从所有 Ast 删除对该 Geo 的引用 |
| 添加动画 | 自动设置默认类型为当前 Ast 允许的类型 |

### 材质导出设置

#### 前置条件

至少有一个 Ast 添加了模型引用。否则材质区域显示提示且无法编辑。

#### 操作步骤

1. 勾选 **材质导出设置**
2. 在 **材质名** 下拉选择材质（只显示被引用 Geo 中使用的材质）
3. 设置 **类型**（Class）
   - 新建材质时根据所属 Geo 类型自动匹配
   - 匹配规则：精确匹配 > 前缀匹配 > 去后缀匹配
   - 例：`LandmarkModel` -> `Landmark`；`DecalGeometry` -> `DecalMaterial`
   - 无匹配则保持默认

4. 下方贴图列表自动生成贴图槽位（槽位名来自 `MaterialInfo.json`）
   - 插件沿节点图自动匹配贴图，也可手动选择
   - 每行最右侧是 **通道** 下拉：`BaseColor`（默认，整图直出）/ `Alpha`
   - 选 `Alpha` 时，导出会把该贴图的 alpha 通道抽成独立的 `<名字>_Alpha.png` 灰度贴图
     （R=G=B=alpha，**不取反**），并在 `.mtl` 中作为独立贴图引用
   - 该下拉对**任何槽位**都可用，不限于 `Opacity` 槽；没有 `Opacity` 槽的材质类
     （如 `DecalMaterial`、`Unit`）同样能把任意一行标成 `Alpha`
5. **自动匹配贴图**：点击列表下方的按钮，按节点连线把贴图槽填一遍
   - 默认只填**空**槽，你已经手动选过的行不会被改
   - 勾上按钮右侧的 **覆盖已有值** 则连已有值一起按连线重算

#### 自动匹配怎么判

匹配只看**节点连线**，不看贴图文件名：

| 这张图接到 BSDF 的 | 通道填 |
|---|---|
| `Color` 输出 -> `Base Color` 口 | `BaseColor`（整图） |
| `Alpha` 输出 -> `Alpha` 口 | `Alpha` |
| `Color` 输出 -> `Alpha` 口 | `BaseColor`（整图，图本身已是独立灰度透明图） |

- 槽位名先在 BSDF 输入口里找同名口。BSDF 上没有 `Opacity` / `Cutout` / `Mask` 口，
  这几个槽位名按 **`Alpha` 口** 找。
- 一张 RGBA 图的 `Color` 口可能同时接 `Base Color` 和 `Alpha`。
  这时透明类槽位取 `Alpha` 口那条，其余取 `Color` 口那条 —— 否则 `Opacity` 槽会被填成整张彩图。
- 点按钮默认只填**空**槽，不动你已经手动选过的行；勾 **覆盖已有值** 则全部重算。
- 生成槽位时也有一次自动回填，只处理 `Opacity` / `Alpha` / `Cutout` / `Mask` 这几个槽位名，
  且只认「图的 **Alpha 输出** -> BSDF **Alpha 口**」那种共享 RGBA 图的接法。
  独立灰度图（图走 `Color` 输出）不会被回填，需要手动选或点 **自动匹配贴图**。
- 手动改过之后以手动为准，后续刷新槽位不会覆盖

#### 批量修改材质类型

1. 输入 **材质关键字**
2. 选择 **目标材质类型**
3. 点击 **按关键字修改材质类型**

#### 贴图设置

- **贴图压缩率**：`1.0`（不压缩）/ `0.75` / `0.5` / `0.25` / `0.125` / `0.1`
- **内置贴图导出脚本**：`None` 或 `WuwaNormal`（鸣潮法线贴图拆分）
  - `WuwaNormal` 只作用于槽位名含 `Normal` 的行；已被标成 `Alpha` 的行不参与，两者互斥
- **自定义贴图导出脚本**：选择自定义 Python 脚本

### ArtDef 导出设置

向 Civ6 ArtDef XML 文件注入元素。

1. 勾选 **是否导出Artdef**
2. 选择 ArtDef 文件（`Units.artdef` 或 `Leaders.artdef`）
3. 点击 `+` 添加实例，设置 Type 和 Value
4. 导出时自动注入 XML 元素到对应集合
