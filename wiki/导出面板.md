# 导出面板

将 Blender 场景导出为 Civ6 资产文件（`.fgx`、`.ast`、材质、ArtDef）。

面板分为四个区域：常规设置、模型导出、动画导出、引用文件设置。底部为导出按钮（至少勾选一项导出选项时启用）。

---

## 常规设置

设置 **项目路径**，指向你的 Civ6 Mod 项目文件夹。

- 路径下必须存在 `Assets/` 文件夹（需先运行一次 AssetEditor 创建）
- 示例路径结构：`MyMod/Assets/Geometries/`、`MyMod/Assets/Animations/`
- 设置路径后，下方各区域才会启用

---

## 模型导出设置

将网格模型导出为 `.fgx` 格式。

### 操作步骤

1. 勾选 **模型导出设置** 展开面板
2. 点击 `+` 创建新的几何体文件（Geo），输入文件名
3. 选中该 Geo，设置 **类型**（Class）

   | 类型 | 用途 |
   |------|------|
   | Unit | 单位模型 |
   | Leader | 领袖模型 |
   | Leader_ShadowVolume | 领袖阴影体积 |
   | LandmarkModel | 地标/建筑模型 |
   | LandmarkObstructionProfile | 地标遮挡体 |
   | VFXModel | 特效模型 |
   | WonderMovieModel | 奇观电影模型 |
   | DecalGeometry | 贴花几何体 |
   | UILensModel | UI透镜模型 |

4. 点击右侧 `+` 添加网格对象（自动添加当前选中的 Mesh，若网格有父级骨架则一并导出）
5. 设置 **导出UV数量**

   | UV 数量 | 说明 |
   |---------|------|
   | 1（默认） | 基础颜色、金属度、粗糙度、法线等 |
   | 2 | 额外支持 AO、光照贴图，**但会丢失骨骼绑定** |
   | 3 | 同时支持 UV2 功能和骨骼绑定（推荐） |

6. **三角化**：模型含四边面/多边面时勾选，已是三角面则无需勾选

### 注意事项

- Unit 骨骼限制 **60 根**，Leader 限制 **256 根**
- 可创建多个 Geo 文件，各自包含不同网格
- 删除 Geo 时自动清理所有 Ast 中对该 Geo 的引用

---

## 动画导出设置

将 Blender Action 导出为 `.fgx` 动画文件。

### 操作步骤

1. 勾选 **动画导出设置** 展开面板
2. 点击 `+` 添加动画条目（类型自动设为当前 Ast 允许的类型）
3. 选择 **动作**（Blender Action）
4. 设置 **类型**（Class）

   | 类型 | 用途 |
   |------|------|
   | Unit | 单位动画 |
   | Leader | 领袖动画 |
   | Landmark | 地标动画 |
   | VFX | 特效动画 |
   | WonderMovie | 奇观动画 |
   | CameraAnimation | 摄像机动画 |

5. **按关键字添加**：输入关键字，点击按钮批量添加名称包含该关键字的动作
6. **压缩动画**：默认开启，减小文件体积

### 注意事项

- 动画类型必须与 Ast 类型匹配，否则在 Ast 引用中无法选中
- 修改动画类型时，所有 Ast 中不匹配的动画引用会被自动清空
- 坐标转换自动处理（Z-up -> Y-up，100 倍缩放）

---

## 引用文件设置

生成 `.ast`、材质、ArtDef 文件。

### Ast 导出设置

Ast 文件将模型、动画、行为组合为 Civ6 资产引用。

#### 操作步骤

1. 勾选 **引用文件设置** > **Ast导出设置**
2. 点击 `+` 创建 Ast 文件
3. 设置 **文件名**、**类型**（Class）和 **DSG**

   类型决定可用的 DSG 和允许引用的 Geo/Anm 类型：

   | Ast 类型 | 允许的 Geo 类型 | 允许的 Anm 类型 |
   |----------|-----------------|-----------------|
   | Unit | Unit | Unit |
   | Leader | Leader, Leader_ShadowVolume | Leader |
   | Landmark | DecalGeometry, LandmarkModel, LandmarkObstructionProfile | Landmark |
   | VFX | VFXModel | VFX |
   | FireFX | FireFXModel | VFX |
   | WonderMovie | DecalGeometry, WonderMovieModel, WonderMovieCamera, LandmarkObstructionProfile | WonderMovie |
   | UILensAsset | UILensModel | （无动画） |

   DSG 决定动画槽位，修改类型时自动重置为第一个可用 DSG。

4. 选择引用类型标签：**模型引用** / **动画引用** / **行为引用**

   **模型引用**：
   - 点击 `+` 添加，下拉只显示类型匹配的 Geo
   - 类型不匹配的引用标红显示并自动删除

   **动画引用**：
   - 槽位由 DSG 自动生成，不可手动增删
   - 每个槽位显示名称（如 `IDLE_A`、`RUN_A`、`DEATH_A`）
   - 只能选择类型匹配的动作
   - 点击 **一键匹配动画**，按 `{Ast名}_{槽位名}` 规则自动匹配

   **行为引用**：
   - 点击 `+` 添加，选择关联的 Ast 文件

#### 类型约束系统

三层保护防止类型错误：

1. **下拉过滤** - Geo 和 Anm 下拉只显示当前 Ast 类型允许的选项
2. **标红提示** - 列表中不匹配的引用显示红色 ERROR 图标
3. **导出阻断** - 导出时验证所有引用，不匹配则弹窗报错并中止

#### 联动行为

| 触发操作 | 自动行为 |
|----------|----------|
| 改 Ast 类型 | 重置 DSG，重建动画槽位 |
| 改 Ast DSG | 重建动画槽位 |
| 改 Geo 类型 | 从所有 Ast 删除不匹配的引用 |
| 改 Anm 类型 | 清空所有 Ast 中不匹配的动画槽 |
| 删除 Geo | 从所有 Ast 删除对该 Geo 的引用 |
| 添加动画 | 自动设置默认类型为当前 Ast 允许的类型 |

### 材质导出设置

#### 前置条件

至少有一个 Ast 添加了模型引用。否则材质区域显示提示且无法编辑。

#### 操作步骤

1. 勾选 **材质导出设置**
2. 在 **材质名** 下拉选择材质（只显示被引用 Geo 中使用的材质）
3. 设置 **类型**（Class）
   - 新建材质时根据所属 Geo 类型自动匹配
   - 匹配规则：精确匹配 > 前缀匹配 > 去后缀匹配
   - 例：`LandmarkModel` -> `Landmark`；`DecalGeometry` -> `DecalMaterial`
   - 无匹配则保持默认

4. 下方贴图列表自动生成贴图槽位（槽位名来自 `MaterialInfo.json`）
   - 插件沿节点图自动匹配贴图，也可手动选择

#### 批量修改材质类型

1. 输入 **材质关键字**
2. 选择 **目标材质类型**
3. 点击 **按关键字修改材质类型**

#### 贴图设置

- **贴图压缩率**：`1.0`（不压缩）/ `0.75` / `0.5` / `0.25` / `0.125` / `0.1`
- **内置贴图导出脚本**：`None` 或 `WuwaNormal`（鸣潮法线贴图拆分）
- **自定义贴图导出脚本**：选择自定义 Python 脚本

### ArtDef 导出设置

向 Civ6 ArtDef XML 文件注入元素。

1. 勾选 **是否导出Artdef**
2. 选择 ArtDef 文件（`Units.artdef` 或 `Leaders.artdef`）
3. 点击 `+` 添加实例，设置 Type 和 Value
4. 导出时自动注入 XML 元素到对应集合
