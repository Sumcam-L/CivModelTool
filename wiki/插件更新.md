# 插件更新

插件内置从 GitHub 自动检查和安装更新的功能。

---

## 自动检查

- Blender 启动 3 秒后自动检查 GitHub 是否有新版本
- 可在 `编辑 > 偏好设置 > 插件 > Civ6ModelTool` 中关闭自动检查
- 默认开启

## 更新流程

1. 发现新版本时，侧栏顶部出现 **插件更新** 面板
2. 点击 **立即更新**
3. 下载 zip -> 解压 -> 覆盖安装
   - 跳过 `.git`、`.serena`、`__pycache__` 目录
   - 相同文件（MD5 一致）不覆盖，避免触碰锁定的 DLL
   - 安装后自动清理 `__pycache__`
4. 自动热重载（`addon_disable` + `addon_enable`），无需重启 Blender

## 手动检查

在 `编辑 > 偏好设置 > 插件 > Civ6ModelTool` 中：
- 查看当前版本和远程版本
- 点击 **检查更新** 按钮
- 点击 **立即更新** 按钮执行更新
